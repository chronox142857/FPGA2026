# 接线与首次启动

主项目目录：`E:\FPGAproject\FPGA2026`。封装引脚来自本机领航者 7010 配套 FPGA 例程；2026-10-29 用户实物照片已确认 J3 上有相应球位丝印，以下按丝印定位，不虚构连接器数字针号。

当前也支持[SD卡自动启动](SD_BOOT.md)，首次独立冷启动及KEY0翻页已通过：卡内保留BOOT.bin，BOOT_CFG 1/2均OFF。下文临时JTAG下载的断电限制仅针对该调试方式。SD启动阶段使用7010专用FSBL初始化DDR；应用采集缓存与运行布局不变。

## 引脚来源与分配

当前整合固件借用开发板原有 **RGB LCD 连接器中的数据线** 接入探头和 ST7735S SPI 屏，不使用并行 RGB 显示协议。用户实物照片确认这些信号也引到了 J3 的普通排针，可直接按 J3 丝印接杜邦线，不需要 FPC 转接板。J3 与 RGB LCD 口复用相同 IO，不能视为独立资源；不得同时连接并行 RGB 面板。本机参考文件：

```text
E:\FPGAproject\ZYNQ_7010_FPGA\ZYNQ_7010_FPGA\21_lcd_rgb_colorbar\prj\lcd_rgb_colorbar.srcs\constrs_1\new\lcd_rgb_colorbar.xdc
E:\FPGAproject\ZYNQ_7010_FPGA\ZYNQ_7010_FPGA\11_key_led\prj\key_led.srcs\constrs_1\new\key_led.xdc
E:\FPGAproject\ZYNQ_7010_FPGA\ZYNQ_7010_FPGA\19_uart_loopback\prj\uart_loopback.srcs\constrs_1\new\uart_loopback.xdc
```

这里的 W18 等是 **Zynq 球位名称，不是连接器针号**。LCD_D0..7 对应 B0..7，LCD_D8..15 对应 G0..7，LCD_D16..23 对应 R0..7。用户照片中的 J3 直接以 V17、V18、Y18 等球位标注排针；因此可以找对应丝印旁的针接线，但不能把 V17 解释为连接器第 17 针。

板载连接：50 MHz 时钟 U18；低有效 PL 复位 N16；KEY0/KEY1 为 L14/K16；LED0/LED1 为 H15/L15；板载 USB UART 的 PL RX/TX 为 T19/J15，115200 8N1。

## 彩屏

用户已提供屏幕标记：`DRIVER IC: ST7735S 14PIN HD14008H14 JY`，因此将控制芯片确认为 **ST7735S**；分辨率沿用用户此前提供的128×128。

外接模块引脚为 `GND VCC SCL SDA RES DC CS BLK`，按4线SPI写入接口接线。`14PIN` 一并作为屏体标记记录，不能据此把已提供的8针模块改成14针接线；屏体FPC针脚定义与模块外接排针定义需要分别由各自资料确认。

当前整合版复用`examples/st7735s_pl/`中已点亮的Verilog驱动：profile 2、X/Y偏移2/3、MADCTL=C8、RGB565高字节先发；复位低100ms、释放后150ms、Sleep Out后150ms；约250kHz，逐字节CS，字节结束SCK保持高。ARM通过AXI画布提交波形和协议结果，不再使用旧GPIO/硬件SPI初始化。屏幕读取关闭，接线保持不变，VCC使用3.3V。

独立五色/文字版和整合版界面已有用户实物确认；UART/SPI真实引脚回接已通过所记录配置，I²C、独立设备和完整速率范围待验证。显示偶发局部乱码尚未解决，旧ARM诊断结果在VALIDATION.md中作为历史保留。

## 实物照片确认的备用屏接线（2026-10-29）

用户第二张照片中，小屏背面排针在照片方向从左至右依次为 `BLK CS DC RES SDA SCL VCC GND`。芯片丝印 ST7735S；板上可见 Q1、R1/R2/R3 和 C1，未见明显独立稳压芯片。设计接线要求 3.3V 供电、3.3V 逻辑。2026-10-30 用户确认此前实际将 VCC 直接接到 5V，因此此前“已按3.3V供电”的前提并未得到验证；已要求断电后将白色VCC线改接3.3V再复测。未确认模块具备5V输入稳压电路前不使用5V。照片不能替代背光电路原理图，Q1 的具体连接和型号尚未确认。

2026-10-31后续：用户更换SDA（黄色，屏幕SDA→J3外排V18）线后，在同一发布版程序下确认屏幕正常。一次测试期间文字呈碎点，强制整屏重画后清楚；不因此宣称局部刷新或长期稳定性已验收。UART回接P15→W18已完成100次正常、8次错误停止位核对，其他协议接线/结果见最新VALIDATION.md。

下表匹配当前已生成的 bit 文件，不需要修改引脚。J3 的“内排”指靠开发板中央、核心板的一排；“外排”指靠 PCB 外边缘的一排。操作时以实际丝印为准，不凭图片左右方向记忆。

|---|---|---|
| GND | GND | 外排，电源端两个 GND 任取一个 |

应断电接线；拔除并行 RGB 屏，保持未使用的采集/自测针脚断开。串联电阻不用于证明 BLK 是逻辑输入，若模块实际要求背光供电，仍需按模块资料配置独立限流/驱动。当前驱动按高电平使能背光，极性需实测。

2026-10-30用户确认已将VCC改为3.3V并重新上电。重新下载后仍为白屏；随后以屏幕端GND为参考，用户实测VCC=3.2728V、RES=3.30V、CS=3.30V。这些是静态直流读数，说明测量当时供电存在、复位释放、片选处于不选中状态；不证明复位脉冲、SPI时钟和数据时序已正确到达屏幕。

## 新购 RGB 触摸屏

用户商品截图标注：4.3 英寸、800×480、IPS、24 位 RGB 显示接口；电容触摸芯片 GT1151/GT9147、I2C 接口，宣传兼容正点原子 RGB 接口。按此作为后续主屏目标；具体到货芯片、FPC 针序/接触面、供电和像素时序仍以卖家配套资料及实物为准，不能仅因针数相同就插接。

GT1151/GT9147 负责触摸坐标，不是 ST7735S 式显示控制器；新屏需要 RGB 扫描显示通路和相应触摸驱动，不能直接沿用 SPI 显示固件。到货前不要将新屏接入当前 bit 文件所驱动的 LCD 口。

**重要资源约束：J3 大量引脚与 RGB LCD 口电气复用。** 新 RGB 屏启用后，不能仅把探头从 LCD 口“搬到 J3 同名针脚”就认为消除了冲突。采集通道和自测输出必须重新分配到不与显示/触摸复用的空闲 IO；如摄像头接口等候选资源需进一步核对。该重新分配尚未实施，当前构建仍是备用 ST7735S 方案。J4 大部分 IO 属于 7020 独有 BANK13，不作为本项目 7010 的可用扩展口。

核对依据：用户提供的四张照片及截图、[正点原子领航者硬件资源说明](https://www.openedv.com/thread-331198-1-1.html)。本次只更新接线文档和约束注释，不改变引脚值或生成文件。

## 自测回接

先将测试发生器关闭（复位默认关闭），再接回路。只能将测试输出接到本项目的输入，不能接到其他正在输出的信号。

2026-10-31用户已确认四根SPI回接线P15→W18、P16→W19、V16→R16、W16→R17接好并重新上电。同一整机程序下SPI四模式/四档预触发的自动及手动核对均通过，共32组；用户确认文字清楚、显示正常。测试结束已关闭发生器输出，保留冻结记录和解析页。I2C上拉电阻目前缺少，未进行实物测试。

| 测试 | 回接 | 额外要求 |
|---|---|---|
| UART | test_io[0] → CH0 | 共地 |
| I²C | test_io[0] → CH0，test_io[1] → CH1 | SCL/SDA 各用适当电阻上拉至 3.3V，例如短线低速演示可先用 4.7 kΩ；确认边沿满足采样要求 |
| SPI | test_io[0..3] → CH0..3 | 共地 |

I²C 测试源是开漏输出，未加上拉时释放状态可能悬空。内部仿真使用理想上拉，不替代硬件上拉验证。

## 首次运行

1. 核对板卡型号、PS 33.333 MHz 参考时钟、PL 50 MHz 时钟和上述排针连接。工程关闭 DDR，也不启用 SD/QSPI/MIO 外设，不使用未经核实的 DDR 参数。
2. 保持外部输入断开，构建并打开串口 115200 8N1。
3. 将启动方式设为适用于 JTAG 的配置，连接下载器、供电。按板卡手册操作启动拨码。
4. 运行 `scripts/program_jtag.ps1`（会检查完成标记，避免旧版 xsct.bat 错误返回0被误判成功），或通过 SDK/XSCT 手动运行 `scripts/program_jtag.tcl`，或者在 SDK 选择生成的 HDF、bit 和 ELF。脚本仅用于易失性下载，不写 Flash。
5. 临时下载后保持供电，断电需要重新下载。排查显示期间不要按复位键；PS复位会回到启动ROM，PL复位若打断AXI访问可能使调试访问超时。程序直接进入逻辑分析仪状态页；KEY0切页，长按KEY1采集。检查串口版本与寄存器 ID；LED0 为慢心跳，LED1 为采集完成指示。
6. 运行 `color` 检查屏幕。若白屏、偏移或颜色颠倒，先核对ST7735S模块的初始化资料、供电/接线；显示参数集中在 `la_display.v` 的驱动实例中。
7. 接自测回路，再按 USER_GUIDE 的三类演示命令逐项验证。

由短盘符生成的 SDK 工作区同样引用该盘符。JTAG 调试前可手动将仓库映射回原盘符，例如在确认 T: 空闲后使用 `subst T: E:\FPGAproject\FPGA2026`，退出调试后 `subst T: /D`。`build.ps1` 在构建期间会自动管理该映射。
