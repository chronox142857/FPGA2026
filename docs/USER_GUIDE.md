# 使用与演示

首次接线和启动见 HARDWARE.md。所有设置作用于下一次采集。上一次完整记录在下一次完成前仍可在界面查看；状态页显示当前硬件状态。

## 按键

| 操作 | 行为 |
|---|---|
| 非编辑状态短按 KEY0 | 状态 → 波形 → 解析 → 设置，循环切页 |
| 非编辑状态短按 KEY1 | 当前页进入编辑（状态页除外） |
| 编辑状态短按 KEY0 | 移到下一个可编辑项目 |
| 编辑状态短按 KEY1 | 增加/循环该项目的值 |
| 长按 KEY0（700 ms） | 先退出编辑，再长按返回状态页 |
| 长按 KEY1（700 ms） | 启动采集；运行中则取消，并关闭循环模式 |

波形编辑顺序：BANK、ZOOM、向左、向右。BANK 0 为 CH0..3，BANK 1 为 CH4..7。ZOOM 每档使一个水平像素对应的采样点数翻倍，Z0 为每像素一个点。最左侧 16 像素为通道标签，黄色竖线为触发位置。

解析页可以翻看每组 7 条事件，以及切换候选。时间单位微秒，数据为十六进制；SPI 用 TX/RX 双字节形式，I²C 地址显示为7位地址和 READ/WRITE，数据字节显示 ACK/NACK。黄色 AMBIGUOUS 表示当前波形存在多个合理解释。红色条目表示 ERR 帧错误或 TRUNC 截断。I²C NACK 在读事务最后一个字节可能是正常结束行为。

设置页掩码显示为十六进制：bit0 为 CH0。`SPI MODE` 显示 0 表示自动，1..4 表示模式 0..3。`ROLE 0..3` 对 UART 为 TX；对 I²C 为 SCL/SDA；对 SPI 为 SCK/MOSI/MISO/CSn。`TEST GEN` 为 0关闭/1UART/2I²C/3SPI。

## 串口

115200 8N1，命令以回车或换行结束。十进制与十六进制参数如下表。

| 命令 | 功能 |
|---|---|
| `run` / `stop` | 开始 / 取消并关闭循环 |
| `status` | 当前状态、已有记录和候选数量 |
| `rate 1` / `5` / `10` / `25` / `50` | 采样率，单位 MSa/s |
| `trigger M C` | M=0立即/1上升/2下降/3电平；C=0..7 |
| `pre N` | N=0..3，对应0/25/50/75% |
| `mask FF` | 启用通道，十六进制，非零 |
| `level 03 01` | 电平参与掩码/目标值，十六进制 |
| `group 0F` | 自动识别候选通道，十六进制，最多4位 |
| `proto 0` / `1` / `2` / `3` | AUTO / UART / I²C / SPI |
| `roles 0 1 2 3` | 手动信号角色 |
| `baud 0` | 自动估计；其他值为手动9,600..1,000,000 |
| `mode -1` | SPI 自动模式；0..3 为指定模式 |
| `test P M [E]` | 发生器协议 P=0..3，SPI模式M=0..3；可选E=1注入UART停止位错误，省略为0；下一次run时应用 |
| `loop 0` / `1` | 单次 / 循环；打开循环后自动开始 |
| `page 0`..`3` | 选择状态/波形/解析/设置页 |
| `candidate N` | 选中已存在的候选，索引从0开始 |
| `color` | 显示红绿蓝白条2秒，检查屏幕颜色与偏移 |
| `dump` | 导出上一次完整记录，不改变正在采集的数据 |

输入其他命令显示帮助。串口是辅助工具，按键与屏幕可以完成基本采集和设置。

## 自测演示

先按 HARDWARE.md 接线。每组命令逐行发送；`run` 后等待 DONE。

### UART 自动波特率

```text
rate 5
mask 01
group 01
proto 0
trigger 2 0
pre 1
test 1 0
run
```

预期：UART，约115200 baud；波形可见起始位、8位数据和停止位，解析得到测试字节。可执行 `page 2` 查看结果。

### I²C 地址与 ACK

```text
rate 5
mask 03
group 03
proto 0
trigger 0 0
pre 0
test 2 0
run
```

预期：I²C，约100 kHz；测试源循环发送原始地址字节 A0（7位地址50、写）及一个变化的数据字节，并输出 ACK。自测源模拟整条总线的 ACK，不包含真实从机。

### SPI 及模式歧义

```text
rate 5
mask 0F
group 0F
proto 0
trigger 2 3
pre 1
test 3 0
run
```

预期：包含 SPI 候选，约100 kHz，显示 AMBIGUOUS。选中不同候选可以观察模式或方向差异。

手动核对已知接线与模式：

```text
proto 3
roles 0 1 2 3
mode 0
run
```

此时显示 MANUAL；MISO 为 MOSI 的按位取反。将 `test 3 1` 和 `mode 1` 同时设置为1，再次 run；同理验证2、3。测试源需保留最后的完整时钟边沿后才释放 CS，仿真对此有贯通检查。

### 未确定与异常

将输入接到已核实的稳定电平、关闭发生器并立即触发采集，预期 UNKNOWN。不要以悬空输入代替稳定电平。

板载 UART 错误演示（每组8帧中破坏一帧的停止位）：

```text
rate 5
mask 01
test 1 0 1
proto 1
roles 0 1 2 3
baud 115200
trigger 0 0
pre 0
run
```

预期为 MANUAL UART，错误计数非零，解析页包含红色错误条目。自动模式遇到这个错误比例时可能返回 UNKNOWN，这是保守识别行为。`test 1 0` 恢复正常发送。设置页的 `TEST ERROR` 也可切换错误注入。I²C 截断、SPI 截断在自动化测试中有独立激励。

## 导出格式

`dump` 输出 CAPTURE 行（采样率、点数、掩码、触发位置）、TICKS 行（64位十六进制基准），随后每行32字节的十六进制样本，END 结束。各行拼接后就是按时间顺序的 CH7..CH0 原始采样，不是物理环形顺序。

导出通过115200串口需要数秒，期间界面与命令处理可能暂停；连续采样无间隙不是首版目标。
