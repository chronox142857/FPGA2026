## 后续分工和顺序

- 本对话负责领航者板上的Verilog采样/触发/缓存/接口、ARM裸机识别和解析、显示/按键/启动、测试与文档。
- 外部STM32等单片机信号源由用户另一个对话开发，本对话不承担该固件实现，也不自动给另一个对话发送消息。
- 可直接转交另一对话的任务书见[STM32独立信号源开发要求](STM32_SIGNAL_SOURCE_REQUIREMENTS.md)，明确型号确认、接线、独立操作、测试包、协议/异常用例及交付物。
- 原范围识别UART、I²C、SPI。若单片机发送自定义上层业务帧，当前恢复底层字节，不会自动理解新增业务协议语义。
- 优先补显示稳定性与板内可独立完成的验收；外部源就绪后导入已知数据和源参数，完成独立时钟、完整速率、触发/异常/角色换序测试，再完成三协议演示。
- 使用现有小屏无需新显示模块；I²C总线需要合适的上拉，若信号源已有则核对后复用。外部源与采集端共地，使用与当前输入匹配的3.3V逻辑。具体信号源板引脚由另一对话确定。
