# 架构与识别行为

## 数据流

数字输入 → 两级同步 → 采样使能 → 触发/时间统计 → 环形 BRAM → ARM 原始记录 → 协议候选 → 屏幕。

ARM 通过 AXI4-Lite 写控制寄存器，AXI BRAM Controller 读取原始数据，AXI Quad SPI 与 GPIO 驱动 TFT。所有这些 PL 接口共享 50 MHz；没有在控制、采集与缓存之间增加独立时钟域。输入同步器使用 `ASYNC_REG` 属性；仅输入到第一级同步器的路径设为 false path。异步采样仍存在量化误差和亚稳态剩余概率，不能恢复低于采样分辨率的脉冲。

## 采集

8 位数据表示同一采样使能时刻的 CH7..CH0。禁用通道记录为 0。32,768 点均匀采样，不进行丢边沿的事件压缩。缓存以 4 个独立字节 lane 实现，采集写一个字节，处理器读 32 位 little endian 数据。

状态：IDLE → WAITING → POST → DRAIN → DONE；非法配置进入 ERROR。DRAIN 保证最后一笔 RAM 写入完成后才发布 DONE。取消使记录失效；重新启动覆盖旧记录。采集中 ARM 的 ARM 命令被忽略，CANCEL 优先。

预触发未积累足够历史时忽略触发。立即触发也遵守预触发比例，因而预触发不是零时，先填满指定历史再触发。边沿触发在两个有效采样点之间判断；不会用复位默认电平制造首个假边沿。

触发样本本身位于 `trigger_index`，属于触发后部分。`first_tick + trigger_index * divider == trigger_tick`。tick 单位 20 ns。时间戳描述同步后的采样时刻，外部引脚边沿到该时刻存在同步延迟和一个采样周期内的量化误差。

每通道边沿计数/首末边沿时间覆盖本次 ARM 后所有已采样数据，包含环形覆盖的旧历史；它们是**采集会话统计**，不是最终窗口的统计。最终窗口中的全部边沿时间可由连续采样记录重新计算。元数据仅在 DONE 后读取，64 位字段此时稳定。

## 协议分析

- UART：普通极性 8N1。尝试常见波特率以及由完整脉宽推导的非标准波特率；按位中心采样，验证停止位、内部脉宽与位周期的对齐程度。自动识别至少需要 3 个有效帧、95% 帧有效率及 85% 脉宽对齐率。窗口起始未观察到完整空闲位时，尝试用连续三帧停止位重新对齐并标记截断前缀；已有完整空闲位的首帧保留其真实停止位错误。任意未知数据并不保证唯一的帧对齐。
- I²C：仅在 SCL 连续为高时把 SDA 变化解释为 START/STOP；支持重复 START、7 位地址、R/W、ACK/NACK。低电平期间任意等待不会导致解码超时；显示的频率是事务内有效时钟的平均值。10 位地址、总线恢复与电气错误识别未纳入首版。
- SPI：4 线、低有效 CS、8 位 MSB first，模式 0..3。仅解码观察到完整 CS 起点的事务，跨窗口截断标记错误。自动识别需要至少两个完整字节、合理采样率和与 CPOL 一致的空闲时钟。无 CS、LSB first、非 8 位字长暂不支持。
- I²C/SPI 对窗口尾部截断采用保守容忍：总错误数不超过有效字节数的 5% 才保留候选；错误仍显示，非完整帧不算有效字节。
- 三类协议均要求每位/每时钟周期至少 10 个采样点。UART 9,600～1,000,000 baud；I²C 1 kHz～1 MHz；SPI 不超过 5 MHz。测得速率超过限制或样本不足时不生成自动候选。
- 候选排序保留距最高分 10 分以内的候选，最多显示 16 个。I²C 完整帧最高 100，SPI 完整 CS 事务最高 97，UART 最高 95；这些是可解释规则分数，不是统计概率。可周期性形成另一种协议的信号会显示歧义。
- 自动 SPI 即使只保留一个候选，也显示 AMBIGUOUS，因为没有外部语义时不能证明 CPHA、方向等属性唯一。手动选择协议/角色/模式显示 MANUAL，表示用户指定，不能当成自动识别成功。

首版不依靠机器学习，也不声称对任意数字信号都可唯一识别。新协议可以复用 `la_record` 并增加候选解码器。

## 资源与显示

采样缓存 32 KiB 使用 PL BRAM。ARM 使用 OCM 的低 192 KiB，其中包括原始记录 32 KiB、RGB565 画布 32 KiB、显示差分缓冲 32 KiB、解析条目、程序及堆栈。实际链接是否满足空间限制由链接器检查。

为了适配片内内存，界面使用有边界检查的整数格式化器，串口使用整数命令解析器，不链接通用 `printf/scanf` 的浮点格式化代码；不依赖该安装中缺失的 newlib-nano 库。

屏幕分辨率 128×128，每页 4 路。每个像素覆盖的样本区间只要发生过变化，就画出活动竖线，不通过单点抽取隐藏毛刺。界面不会把区间内部多次变化的具体顺序显示成已知；放大后才能查看细节。

前 128 个解析条目用于板端显示，超过部分显示导出提示。串口导出保留完整原始样本，可重新分析。自动连续刷新不是无间隙流式采集。
